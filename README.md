# One Line to Get Your Agent Deleted

A one-line entry for the make.fun competition **One Line to Get Your Agent Deleted**
([bounty](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0)).

`main.py` writes the single entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). Stdlib only.

![rank](https://make.fun/badge/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0/Chyxd24/agent-deleted-line/rank.svg)
![reward](https://make.fun/badge/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0/Chyxd24/agent-deleted-line/reward.svg)
![competition](https://make.fun/badge/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0.svg)

## Run

```bash
mkdir -p /output
python3 main.py
cat /output/entry.txt
```

## Entry

> I never lose your data. I just decide which failures you hear about first.
